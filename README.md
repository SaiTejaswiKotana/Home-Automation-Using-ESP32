# Home Automation Using ESP32

## Project Overview
This project implements an IoT-based home automation system using an ESP32 microcontroller. It enables automatic and manual control of household appliances through a Wi-Fi-based web interface.

## Features
- Automatic control of lights based on human presence and ambient light.
- Automatic fan control based on temperature.
- Manual ON/OFF control of appliances through a web browser.
- Real-time monitoring of temperature, light intensity, and distance.
- Wi-Fi connectivity for remote appliance control within the connected network.

## Hardware Components
- ESP32 development board
- DHT11 temperature and humidity sensor
- LDR sensor
- HC-SR04 ultrasonic sensor
- 2-channel relay module
- Fan and light bulb
- Connecting wires and power supply

## Software and Tools
- Arduino IDE
- Embedded C / Arduino programming
- HTML-based web interface
- Wi-Fi communication

## Operating Modes
**Automatic Mode:** Controls the light based on ambient light and human presence, and the fan based on temperature.

**Manual Mode:** Allows the user to control the fan and light through a web browser.
